# Falcon 9 First-Stage Landing Prediction
IBM Data Science Capstone project.

## What's inside
- 01_data_collection_api.py: SpaceX API data collection
- 02_web_scraping.py: Wikipedia scraping
- 03_data_wrangling.py: cleaning and feature preparation
- 04_eda_visualization.py: EDA charts
- 05_eda_sql.py: SQL analysis
- 06_folium_map.py: interactive launch-site maps
- 07_dash_app.py: Plotly Dash dashboard
- 08_predictive_analysis.py: classification models

## Results
Best model: Logistic Regression, 83.33% test accuracy (tied with SVM and KNN).
